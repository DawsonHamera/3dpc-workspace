# Dev Log - File Storage & User Assets

## Overview

Implemented a general file storage system using Cloudflare R2 with database tracking, upload handling, storage limits, and user avatar support.

## Completed

### File Storage System

- Added a generic `files` table for storing uploaded assets
- Integrated Cloudflare R2 storage service
- Added file upload endpoint
- Added database records for uploaded files
- Added file retrieval by ID
- Added file deletion support

### Upload Improvements

- Added filename sanitization
- Generated unique file IDs using UUIDs
- Stored file metadata:
  - Original filename
  - MIME type
  - File size
  - Uploader
  - Metadata JSON

### Storage Management

- Added storage usage tracking
- Added storage quota checks before uploads
- Added per-file size limits
- Added storage metrics endpoint for displaying usage in the client

### User Avatars

- Added avatar upload/update route
- Connected uploaded files to user profiles through `avatarFileId`
- Added client-side avatar upload hook
- Avatar images are served through the API file endpoint

### Client Integration

- Added React Query hooks:
  - `useUpload`
  - `useUpdateAvatar`
  - `useStorageMetrics`

- Added account settings UI for profile image uploads
- Connected file uploads through Hono RPC multipart handling
