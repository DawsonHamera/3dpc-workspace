# Hono RPC Integration

The frontend uses:

```ts
hc<AppType>()
```

to generate typed API calls.

Example:

```ts
api.auth.login.$post()
api.auth.me.$get()
```

This removes the need for manually maintained API request/response types.

---

# Important TypeScript Lesson

If Hono RPC types appear as:

```
Hono<Env, BlankSchema, "/">
```

the route composition is losing its schema.

The exported app type must preserve the chained route definitions.

Problem area:

```ts
export type AppType = typeof app;
```

If `app` has already lost route typing, the client receives no useful types.

Verify:

* child routers export typed Hono instances
* route mounting preserves inference
* avoid patterns that erase the schema

# Ionic Migration Notes

The old UI was built around older React Router assumptions.

Important discovery:

Current Ionic Router dependency requires React Router 5 compatibility.

Installed combination:

```
@ionic/react
@ionic/react-router

react-router 5.x
react-router-dom 5.x
```

Do not upgrade React Router independently.

Old:

```tsx
<Redirect to="/dashboard" />
```

belongs to React Router 5.

Modern React Router 6 uses:

```tsx
<Navigate to="/dashboard" />
```

but upgrading is not currently worth the migration cost.
